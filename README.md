# Cemre'nin Dünyası 🌷

Cemre için yapılmış küçük, kişisel bir site. Telefondan açılır; "Ana ekrana ekle" ile uygulama gibi durur.

- Site: `site/` klasörü (düz HTML/CSS/JS, kurulum gerekmez; `site/index.html`'e çift tıkla)
- Ayarlar: `site/config.js` (mektup, isimler, albüm altyazıları, hangi bölümler açık)
- Yayın: `main` dalına gönderince GitHub Pages'e otomatik çıkar (`.github/workflows/pages.yml`)
- Ahmet için ayrıntılı kullanım kılavuzu: **`site/README.md`**
- Test ekran görüntüleri: `qa-shots/`
